# Assets

Store source/design assets here. These folders are created now, with no generated images or real household records.

| Folder | Contents |
| --- | --- |
| [branding](branding/README.md) | Logo sources, colors, brand guidelines |
| [icons](icons/README.md) | Appliance/navigation icon sources and license notes |
| [illustrations](illustrations/README.md) | Onboarding, energy-saving, and readiness illustrations |
| [screenshots](screenshots/README.md) | Prototype screenshots and sanitized demo captures |
| [references](references/README.md) | Public provider-reference material and attribution |
| [sample-data](sample-data/README.md) | Synthetic or explicitly consented and redacted demo fixtures |

Use descriptive kebab-case names, for example `appliance-electric-fan.svg` or `anteco-advisory-synthetic-01.png`. Record source, author/license, permission, and date for third-party assets. Keep editable masters here; only web-ready approved public assets should later be copied to `public/assets/`.

Private user bill/advisory uploads belong in authorized application storage, never Git or public folders. Redact names, account numbers, addresses, barcodes, and identifiers in demo samples.
